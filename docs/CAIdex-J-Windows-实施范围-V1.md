## 已批准：J-1 应用壳与本地 Chat

目标：交付可下载、可启动的 Windows 正式应用基础，先验证 Tauri 与既有 Rust 核心的连接，再接入账户/同步交互。

有限任务：

1. 建立 Windows 11 x64 Tauri 2 + React/TypeScript/Rust 工程、锁定依赖与最小 IPC 权限；采用既有品牌资产。
2. 实现可折叠侧栏、会话、Composer、Chat/Codex 模式入口、设置导航；Codex 实际执行仍归 K，界面明确当前可用状态。
3. 默认简体中文、可选英文；系统/浅色/深色主题，键盘提交/换行、中文输入法及基本无障碍焦点行为。
4. 接入既有普通 Chat 本地缓存、流式输出/停止/草稿/附件/分支及错误状态；复用核心隔离和 unknown 不重放规则。
5. 接入此设备模型/Provider 配置、实际能力展示、系统凭据保存/替换/移除及独立模型用途；不读取 Host Key。
6. 建立 Windows GUI 定向测试与构建 CI，提供带源码 SHA 的可下载测试产物、启动/配置/操作/预期结果/限制说明。

非目标：本轮不接入账户认证、云 Chat/Memory 同步或记忆管理的可执行 UI；这些完整 J 要求在后续单独批准的内部里程碑完成。也不进入 K Host/审批/Diff、L SSH、iOS、正式 CLI 整合或 Relay。

依赖：既有 Chat/Provider/凭据契约、品牌资产、UI 参考；商业模型与真实用户 Key 不是开发验收前提。定向测试使用合成端点/秘密，不调用商业 API。

通过条件：

- 精确提交的前端类型/构建、Rust 格式/Clippy/定向测试和相关既有回归通过。
- Windows runner 实际构建应用并验证可执行文件启动；核心 IPC 与合成 Chat 交互、停止/未知终态、缓存恢复及 Key 不进入日志/缓存具有可复现证据。
