# CAIdex UI 规范 V1

确认日期：2026-10-06；统一账户、记忆与云同步要求更新于2026-10-08。适用客户端：Windows、iOS。

本文件落实用户的 UI 决定，作为完整方案的 UI 补充。当前工作区尚无客户端代码，本文件记录待实现和待验收的要求。

统一账户、长期记忆、同步与删除语义以[账户、记忆与云端设计及验收 V1](CAIdex-Account-Memory-Cloud-设计与验收-V1.md)为正式依据；本次只更新规范，以下新增页面及交互均未实现、未验收。既有模型/真实 Runtime、Host 授权与阶段顺序保持不变。

## 1. 已确认的设计决定

- 以同平台 ChatGPT/Codex 官方客户端为参考，尽量 1:1 还原布局、控件层级、交互流程和状态反馈。
- 有真实截图或演示的页面优先按对应参考实现；文档示意图用于补充结构和行为。
- 缺失或不确定的部分由开发者沿用相邻页面的设计规则补齐，不再为常规 UI 位置逐项请求确认。
- CAIdex 功能融入已有设置、选择器、菜单和会话卡片。模型 API Key 配置放入设置。
- 使用用户提供的 CAIdex Logo、符号和应用图标；官方截图作为参考资料，页面使用 CAIdex 自有资产实现。
- Windows/iOS 默认简体中文，可切换 English；CLI 保留上游英文交互，不套用本规范的 GUI 布局。
- 保持既定平台、Runtime、凭据归属与同步方案；界面不创造另一套任务执行逻辑。
- 使用 CAIdex 官方统一账户，Windows/iOS客户端直接完成注册和登录；普通用户无需另行部署身份服务器或先访问网站注册。
- 自动记忆、记忆同步、Chat 历史同步及向模型发送记忆的权限分别控制。新账户记忆同步默认关闭；Windows/iOS/CLI登录继承同一账户已有状态，不能重置开关，已Enabled也不自动上传未经授权的历史本地记忆。
- 普通已登录设备与远程 Codex Host 分开管理；登录账户不授予任何 Host 的文件、Shell 或管理员权限。

## 3. 页面布局

### Windows

- 左侧保留新建会话、历史、项目与适用功能入口；底部个人/应用菜单进入设置。侧栏支持折叠。
- 主区域由顶部上下文、会话记录、底部 Composer 组成。输入框随内容增长，会话滚动不移动整个应用框架。
- Chat/Codex 切换位于产品或模式选择位置，文案使用 CAIdex 的名称。Chat 保留普通对话结构；Codex 展示工具、命令、审批和任务状态。
- Codex 上下文区显示当前 Host、项目及分支/Worktree；展开后选择环境和权限策略。主机选择器同时列出本机与远程主机。
- Changes 摘要从会话进入右侧 Diff/审查区域。面板按需打开并可关闭，避免长期压缩普通聊天区域。
- 设置沿用桌面分类导航与内容区结构，新增功能作为相关分类或子页。
- 首次启动可展示欢迎页及登录、注册入口，允许继续使用已有本地能力。未登录主界面右上角显示“登录”“注册”，侧栏底部保留账户入口；登录后右上角两按钮消失，侧栏底部显示头像、昵称及账户菜单。
- 注册、登录、邮箱验证、找回密码和账户恢复直接在应用窗口内完成，登录与注册页可相互切换；返回或取消不清空已有本地会话和配置。
- 支持参考客户端的键盘提交、换行、关闭浮层、焦点移动与快捷键提示；中文输入法组合输入期间不误提交。

### iOS

- 使用原生导航、侧栏/抽屉、Sheet、上下文菜单与返回手势；处理安全区、键盘和系统字号变化。
- Chat 从侧栏进入历史和设置；模式切换沿用顶部产品/模式入口。
- Codex 任务列表提供 Host 筛选；进入任务后显示会话与操作状态。
- 新任务与适用的会话 Composer 上方显示 Host、项目、分支/Worktree、环境上下文；点击对应控件进入选择 Sheet。
- 模型与推理选项保留在 Composer 附近。附件菜单提供当前模式和模型支持的文件、相册及相机入口。
- 审批与用户输入请求先出现在会话内，详情通过 Sheet 展开。
- Changes 摘要进入完整 Diff/源文件页面，支持折叠、行换行、源文件跳转与行内评论。
- Remote 通过 Codex 内的 Host 选择和任务筛选呈现，避免再增加一套重复的 Remote 主导航。
- 未登录时在顶部适当位置显示“注册”及可到达的登录入口，不遮挡模式/Host 上下文；注册、登录、邮箱验证、找回密码和恢复账户使用原生 SwiftUI 导航或 Sheet，登录与注册页可相互切换。
- 登录后收起未登录入口，通过侧栏底部的头像、昵称和账户菜单进入设置。Passkey 使用系统安全认证界面，沿用系统取消和返回行为。

## 4. CAIdex 功能入口

| 功能 | 主要入口 | 具体行为 |
| --- | --- | --- |
| Provider、API Key、自定义 Endpoint | 设置 → 模型与提供商 | Provider 列表进入详情；默认展示 Key 配置、连接状态与测试连接；自定义 Endpoint 等参数放在高级区域 |
| 本地推理/Ollama | 设置 → 模型与提供商 | 配置地址并检测服务；显示可用模型和实际能力；iOS 仅显示该平台已支持的连接或推理方式 |
| 模型与推理强度 | Composer 模型选择器 | 模型按提供商分组，可搜索；推理选项按模型能力呈现；未配置提供商的入口跳转到设置 |
| 默认模型 | 设置 → 模型与提供商 | 分别配置普通 Chat 与 Codex 默认值；会话中的选择仍可覆盖默认值 |
| 远程主机 | Codex Host 选择器；设置 → 远程主机/连接 | 快速选择与完整管理分开；管理页处理添加、配对、连接方式和移除，选择器展示连接状态 |
| 注册、登录与账户设置 | 未登录顶部入口；侧栏底部账户菜单；设置 → 账户与安全 | 应用内邮箱注册/验证、密码或 Passkey 登录、找回/恢复、资料及邮箱修改、登录方式与注销 |
| 已登录设备 | 设置 → 账户与安全 → 已登录设备 | 显示当前设备、设备类型、登录及最近活动时间；单独退出、退出其他设备；不要求新设备获得旧设备批准 |
| 自动记忆 | 设置 → 记忆与个性化 → 自动记忆 | 控制长期记忆的自动提取、整合和使用；不改变记忆同步开关；关闭后仍可查看、修改、删除和导出已有记忆 |
| 同步记忆 | 设置 → 记忆与个性化 → 同步记忆 | 默认关闭；首次开启须登录并确认上传范围；展示账户权威状态、关闭待确认及保留/删除云端的选择 |
| 个人/项目记忆及模型权限 | 设置 → 记忆与个性化 | 管理授权范围内记忆、整合模型及 Provider 记忆权限；来源、版本、纠错和导出可到达 |
| Chat 历史与云同步状态 | 设置 → 云同步 | Chat 历史使用独立开关；展示记忆同步状态、最近时间、错误和未同步数据；使用官方账户服务，不要求配置自托管身份服务器 |
| 项目、分支、Worktree、环境 | Codex 上下文选择器 | 新任务发送前展示选定上下文；已有线程显示其绑定上下文，受 Runtime 约束的项不提供无效编辑 |
| 权限与审批策略 | Codex 上下文权限控件；设置 → Codex | 就地查看当前策略，设置页保存默认值；展示 Host 实际支持的选项 |
| Plugins/Skills | 上游已有的发现/管理入口；设置 → 插件/Skills；Composer 内联选择 | 管理安装、启用状态和来源；本次输入引用的能力在 Composer 中可见 |
| MCP | 设置 → MCP | 先显示当前配置目标；管理服务器、连接和工具状态；会话中的调用用工具卡呈现 |
| Approval、requestUserInput、MCP elicitation | 会话内请求卡；详情弹窗/Sheet | 选项来自当前有效请求；必要信息就地填写，处理后保留结果记录 |
| Queue/Steer | 正在运行的 Composer 附近 | 可就地切换输入用途；队列显示待发送内容；设置 → Codex 只保存默认行为 |
| 停止、继续、Resume | Composer 运行状态控件；会话菜单 | 动作依据 Runtime 能力与线程状态生成，操作后等待实际确认 |
| Diff/Review | 会话内 Changes 摘要；变更查看器 | 展示文件、增删、审查评论和已支持的操作；Windows 用侧面板，iOS 用完整页面 |
| 语言、主题、字号 | 设置 → 常规/外观/语言 | 默认简体中文；主题支持系统、浅色、深色；布局适应本地化文案与字号 |
| 版本与开源许可证 | 设置 → 关于 CAIdex/开源许可证 | 显示客户端、Host/Runtime 版本以及诊断入口 |

设置沿用原有分类导航及同平台菜单层级：常规、外观、语言、模型与提供商、Codex、插件、MCP、Skills、远程主机、账户与安全、记忆与个性化、云同步、安全、高级、关于 CAIdex、开源许可证。原“同步与设备”内容按云同步与账户登录会话拆分；“安全”保留本地/Runtime 安全设置，账户认证归“账户与安全”，避免重复入口或混淆授权目标。

### 配置归属必须可见

- 普通 Chat 配置页显示“此设备”；Codex 配置页显示选定 Host 的名称与连接状态。
- Remote 模型列表来自执行 Host。手机的本地 Chat Key 不自动成为远程任务的 Key。
- 执行 Host 的 Provider API Key 由该 Host 保存和使用。移动端展示配置状态，不读取已保存的远程 Key；支持远程添加/更新时，保存目标必须明确。
- API Key 输入在提供商详情页完成，默认遮蔽；已保存的凭据使用“已配置”状态与替换/移除动作呈现。
- Key 不进入聊天、记忆或普通同步数据库。切换 Host 后重新加载该 Host 的模型、MCP、Skills、权限与连接状态。账户登录不能读取 Host 已保存的 Key；执行端离线时记忆整合显示等待执行端，不把 Key 复制到云服务继续运行。
- 配置页保留未保存编辑；保存结果、测试连接结果和错误在当前页显示。

### 账户流程与登录设备

| 页面/流程 | 必须可见的内容与操作 | 状态要求 |
| --- | --- | --- |
| 注册与邮箱验证 | 邮箱、密码、验证步骤；登录切换；发送/重发及修改邮箱入口 | 验证码一次有效；显示有效期、重发冷却、次数受限与邮件失败状态；提交中避免重复请求 |
| 登录 | 邮箱密码、Passkey、忘记密码、注册切换 | 常规密码登录不每次发送邮件验证码；错误反馈避免泄露某邮箱是否注册；Passkey 取消可返回其他已支持方式 |
| 找回密码/账户恢复 | 邮箱恢复、验证码或恢复链接、重新设置密码 | 链接失效、重复使用、限流及无法接收邮件均有明确反馈；恢复后受影响会话的撤销结果可查看，不以改密码成功冒充所有设备已退出 |
| 账户资料与认证方式 | 头像/昵称、修改邮箱、登录方式、Passkey 管理、退出账户 | 邮箱变更后原有记忆、聊天和项目归属保持；敏感操作先重新认证；新方式确认可用后才能安全移除旧方式 |
| 已登录设备 | 当前设备标记、设备类型/名称、登录时间、最近活动时间、逐项退出及“退出其他设备” | 默认不限制设备数量，无强制绑定或旧设备审批；名称/平台仅为展示信息；撤销等待服务器确认，未确认不显示已退出 |
| 异常登录与安全通知 | 账户内可查看的重要安全事件、异常登录提示及恢复/退出其他设备入口 | 通知不显示秘密；被撤销设备后续云请求失败并转重新登录状态，本地可用能力保持既有权限 |
| 注销账户 | 说明账户、云聊天/记忆/私人项目及相关数据的处理范围；未同步本地数据先处理；重新认证和最终确认 | 注销与退出分别呈现；说明服务端删除进度、本机备份到期窗口和离线设备副本限制，不声称离线设备已立即擦除 |

邮箱注册、密码登录、Passkey、邮箱找回、修改邮箱/认证方式、退出与注销都是正式首版能力，不以“未来可支持”省略。密码字段默认遮蔽，不在状态卡、日志或诊断中回显；验证码、恢复链接及会话令牌不进入聊天和记忆。

账户登录会话使用服务端 `auth_sessions` 的独立撤销与刷新状态；安装标识只改善设备展示，不充当认证凭据。普通设备退出不替代 SSH/Relay/Host 配对撤销；两个管理页分别注明授权对象。云端退出不能保证立即擦除离线设备已下载数据。

未来第三方 OAuth/OIDC 若加入，使用系统安全认证会话及 Authorization Code + PKCE；不在普通 WebView 中收集第三方密码。Windows Passkey 与 Tauri 的系统认证桥接、iOS AuthenticationServices 的接入细节及无障碍焦点行为在 J/K、M/N/O 验证，产品流程不因此改为网页预注册。

### CLI跨平台一致性（待实现）

CLI只登录已有CAIdex账户，不提供注册；Windows/iOS继续应用内注册，无需网页预注册。CLI的系统浏览器PKCE或VPS Device登录会话在“已登录设备”显示对应CLI类型、时间与独立退出入口；不建立必须由旧设备批准的流程。记忆同步是同账户服务器权威状态，CLI自动继承Enabled/Disabled并可修改，所有平台展示版本/待确认一致；既有历史本地记忆仍须归属和首次范围许可。跨端审批来自同一Host有效请求，Windows/iOS/CLI各自必须有独立Host授权，账户登录不授予代审批权限。英文TUI/命令/非交互细节只放[CLI独立规范](CAIdex-CLI-完整交互与验收规范-V1.md)，不改变本文件GUI布局或原16项待实施验收。

任何端重新登录都不能清掉此设备尚未确认的关闭意图并恢复上传；界面同时说明“账户最后确认状态”与“本机等待确认关闭”，不显示第二个独立开关。设备列表显示的CLI会话只代表账户登录；Host审批卡仍展示真实执行目标和授权，不把浏览器/Device登录授权当作工具批准。

退出CLI登录会话的确认页只说明账户/云数据权限撤销及离线副本限制，不把它标为停止Codex任务；Host任务是否运行继续显示真实Host状态。CLI观察端退出或登录取消也不是工具拒绝/任务取消，跨端审批卡仅按Host有效请求更新。此一致性纳入原UI-ACCOUNT-04/UI-HOST-01和CLI-22/30/32待验场景，英文终端细节仍只见CLI规范。

### 记忆与个性化

- 设置页分别展示“自动记忆”“同步记忆”，后者对新账户默认关闭，登录显示服务端已有状态而非重置；继承开启不等于此设备旧本地资料已授权上传。自动记忆的默认值尚未决定，实施前明确；不能由同步开关推导或互相联动。
- 个人记忆与项目记忆分别进入列表，项目页显示当前授权项目。原始 Chat 历史、Codex 执行事件/任务状态、临时任务上下文不当作同一记忆列表混合展示。
- 记忆详情显示来源、时间、有效状态及版本；区分明确决定、偏好、项目文件证据、执行结果、AI 推断和已取代/失效信息。重要内容待验证时显示候选/待核实，不让 AI 推断直接覆盖已确认决定。
- 提供查看、修改、纠正、删除、导出和版本对照；新决定取代旧决定后保留可核对的来源关系。项目代码与实际 Git/测试证据优先，过时记忆需提示并可纠正。
- Chat 模型、记忆整合模型、Embedding 模型分别展示用途与执行端；可复用已配置模型或单独选整合模型。无可用整合模型时提示自动整合暂停，已有记忆保存和基础检索可继续；没有 Embedding 时显示基础检索可用。
- 更换 Chat Provider 不删除或要求重建记忆；更换 Embedding 模型显示向量版本/重新索引状态，不能把新旧向量混算。共享记忆不意味着正在运行的 Codex 线程可跨 Provider 无损迁移。
- Provider 记忆权限是独立授权：明确所选提供商、用途（Chat/整合/Embedding）、处理端及允许发送的个人/项目范围。仅本地处理的记忆不得发送给未授权云端模型；权限不足时提示调整权限或选择本地处理，不暗中放行。
- 固定说明：“关闭 CAIdex 云端记忆同步，不会自动阻止对话或记忆整理向已授权外部模型发送相关上下文。”记忆不能授予 Runtime 审批或工具权限，网页/文件/工具输出不能变成高权限指令。

### 同步记忆与云同步状态

“同步记忆”的唯一开关在记忆与个性化；云同步页展示同一个账户权威状态及跳转入口，不保存第二个可能矛盾的开关。Chat 历史同步独立控制，关闭记忆同步不改变 Chat 同步。状态来自服务器版本和本机待处理意图，不能用最后一次本地开关值冒充全账户确认结果。

| 交互/状态 | 界面和提交行为 | 确认与恢复要求 |
| --- | --- | --- |
| 从未开启/关闭 | 开关默认关；从未开启时注明记忆仅存本地 SQLite；已关闭时按 A/B 区分旧云数据，本地生成、检索、跨模型使用及编辑/导出可继续 | 登录后不自动上传；提示重装/丢失设备可能丢失本地数据，普通 SQLite 缓存不是完整云备份 |
| 首次开启 | 未登录先完成应用内登录；确认待上传的个人/项目范围、本地待处理数据及外部模型权限的独立性 | 用户确认前不上传，权限外项目不进入选择；未登录本地数据归属或迁入范围须显式确认，不能绑定到下一个登录账户 |
| 同步中/完成 | 最近成功时间、未同步数量、当前账户及进度；Chat 与记忆分项显示 | 幂等重试不重复生成条目，断网保留队列；“已同步”仅基于实际服务端确认 |
| 在线关闭 A | 选择“仅停止同步”，说明此前云端记忆保留 | 服务端确认账户级关闭后拒绝所有设备后续新的记忆上传与下载；控制状态与授权删除结果仍可查询 |
| 在线关闭 B | 选择“停止同步并删除云端记忆”；先确认本地保留范围、其他设备尚未同步数据的影响，再最终确认 | 停止同步与删除完成分别显示；删除墓碑/旧队列不会复活记录，说明本机备份保留期及离线设备本地副本仍可能存在 |
| 离线关闭 | 本机立即阻止新的及排队上传/下载，保留本地队列，显示“等待服务器确认关闭”；保留待提交关闭及所选删除意图 | 服务器收到前不宣称其他设备停止；恢复联网先提交并确认设置，不能先自动上传旧队列 |
| 其他设备关闭/旧版本请求 | 接收服务端权威关闭版本，显示由其他设备更新的状态 | 过期客户端不能继续上传/下载；拒绝后保留本地内容，停止提交并刷新状态，不无限重试旧设置 |
| 重新开启/版本冲突 | 再确认范围；展示不同设备存在的修改、删除、重复或待核实条目，提供合并/保留/纠正 | 不把单设备快照覆盖云端或其他设备；云端已删除记录不自动重建，如需重新创建必须明确新操作 |
| 云端删除后的本地副本 | 区分已应用同步删除与用户选择保留的本地副本；说明保留副本的范围 | 保留副本不能隐式重新排队上传；旧设备联网先处理设置版本和墓碑，再处理变更 |
| 云不可用/会话过期 | 云同步页显示网络、认证、服务端或版本错误及未同步数据；提供重新登录、查看原因、允许的重试 | 已配置本地 Codex、项目和模型按既有权限继续工作；无有效账户认证不访问云数据，不能将错误吞为“同步成功” |

关闭同步对话框始终同时解释 A 与 B；不能把 A 表述为“删除以前上传的数据”。B 的云端删除进度不等于删除所有离线副本，备份中的数据在有限保留期限后消失。云端只有 VPS 本机有限备份，无自动异地备份；整台 VPS/磁盘损坏可能同时丢失数据库与备份，客户端缓存不能保证全量恢复。

账户退出或切换前，先列出尚未同步的聊天和记忆，并提供明确的保留在原账户隔离区、导出、按授权完成同步或确认删除等适用操作；无网络或同步关闭时不能强迫上传作为退出条件。待用户处理前不静默丢失数据；完成退出立即隔离原账户本地缓存、索引和队列，新账户不能看到或发送旧账户数据。远程 Host 已有配对权限保持单独控制，账户退出不冒充 Host 授权撤销。

导出和删除页面注明个人/项目范围、云端与此设备的差别；记忆同步关闭时本地导出正常，管理/云导出不能绕过关闭下载记忆正文，保留云数据的导出流程在 I 验证并遵守开启/授权规则。本地删除、云端停止同步、云端数据删除、账户注销使用不同文案及确认，避免一个“清除”按钮隐含多个行为。高级诊断可展示同步版本/错误码，普通流程使用“待确认”“存在冲突”等产品文案。

## 5. 交互状态与缺失部分补齐

| 状态 | 布局与反馈 | 可用动作 |
| --- | --- | --- |
| 空会话/无任务 | 沿用参考空白页层级，显示当前模式与可用上下文 | 输入、附件、选择模型/Host |
| 编辑输入 | Composer 适度增长，附件与上下文保持可见 | 发送、换行、移除附件；草稿按会话保存 |
| Chat 输出中 | 增量更新回复和输出状态，用户上滚后不强制拉回底部 | 停止；回到底部查看最新内容 |
| Codex 执行中 | 同一会话展示 working、工具/命令卡和输出 | 按 Runtime 支持提供 Queue、Steer、停止 |
| 排队/发送中 | Composer 附近展示输入用途、待处理内容与提交状态 | 仅提供后端支持的编辑/取消动作；重试提交保留请求身份 |
| 等待审批 | 请求卡说明目标、动作与有效选项，详情可展开 | 使用 Runtime 返回的批准/拒绝选项 |
| 等待用户输入 | 结构化请求卡或 Sheet，保留已填写内容 | 提交当前有效请求的答案 |
| 审批过期/其他设备已处理 | 原卡保留处理状态，禁用失效按钮 | 查看结果、刷新当前状态 |
| 已完成 | 收束运行状态，保留输出、Changes 与工具记录 | 继续对话、查看 Diff、进入审查 |
| 已停止/执行失败 | 状态落在对应会话或工具卡，展示可理解原因 | 按实际能力继续或重试，避免暗中重跑工具 |
| Host 离线/切换中 | Host 控件和会话状态条说明原因，保留已有内容 | 重连、切换可用 Host；依赖失联 Host 的操作暂不可用 |
| 连接中断/恢复前台 | 显示“状态待确认/正在同步状态”，保留最近已确认状态 | 恢复连接后获取当前状态，再开放依赖该状态的动作 |
| 同步失败 | Chat/记忆分项显示待同步或错误，保留本地数据及队列 | 查看原因与受权限约束的重试；Chat 可用性取决于当前推理服务，已配置本地 Codex 不依赖账户服务在线 |
| 模型不支持当前能力 | 在相关附件/工具/推理选项旁说明原因 | 切换合适模型；不提交明确不兼容的请求 |

补齐规则：常规错误用相关输入项、工具卡或状态条表达；需要决定时使用确认弹窗/Sheet。对话框、提示、菜单、按钮尺寸和动效沿用相邻参考组件。

其他约束：

- 普通 Chat 不展示项目写权限、Shell、Git 等 Codex 操作入口。
- 线程执行中切换模型时，显示实际生效边界；同 Provider 内已验证兼容的模型组合可在下一轮生效。跨 Provider 按既定方案创建关联分支或新线程，提示历史承接范围；不把 UI 选择值冒充正在运行的模型。
- 切换 Host 不迁移正在执行的任务。已有线程保留原 Host 归属，新任务使用明确选择的 Host。
- 网络断连不代表任务停止；恢复前台不自动重新发送已经提交的动作。
- iOS 前台恢复后刷新任务、审批和变更状态，避免以旧审批按钮继续操作。
- 跨设备返回的处理结果更新同一个请求卡，避免重复审批入口。
- 长输出、长文件名、中文/英文文案、软键盘、空数据和深浅主题使用相同的组件约束。

## 7. 实现与验收顺序

整体仍按 F/G → H → I → J/K Windows → L SSH → M/N/O iOS → P CLI → Q Relay → R 验收推进。本规范是后续页面要求，不在当前 F/G 提前实现账户或记忆 UI：I 建立共享核心、账户/API/记忆及同步契约；J/K 接入 Windows；M/N/O 接入 SwiftUI；P按CLI独立规范整合英文TUI/exec/任务/Host/账户及记忆；R 进行真实交互验收。H 保持 Host/SQLite journal/Runtime 既定边界，Q 的 Host 配对设备撤销不与账户登录设备混用。

1. 建立页面/状态清单，绑定参考来源，确定同平台基础组件和品牌资产。
2. 在各自平台阶段实现应用框架、Chat/Codex 切换、会话、Composer、模型选择、应用内注册/登录与设置入口。
3. 落实 Provider/Key、Host、账户与安全、记忆与个性化、云同步、Plugins/Skills/MCP 的设置页和对应快捷入口。
4. 接入真实 Runtime 状态，完成审批、用户输入、Queue/Steer、Changes/Diff。
5. 补齐上表异常状态，使用真实状态或可重复的测试场景验证行为。
6. 对已有截图覆盖的页面按相同窗口/设备尺寸、主题和状态做截图对照；记录差异并修正。

验收要求：

- 已有参考覆盖的区域对照布局、间距、字号、颜色、控件尺寸和交互顺序；自行补齐部分单独标记。
- 常用操作的入口与参考保持一致，CAIdex 功能可从本文件规定的位置找到。
- 模型配置、Host 切换与同步页均能明确展示数据/配置归属。
- 键盘、中文输入、侧栏/Sheet、滚动、返回、草稿保存与深浅主题经过对应平台验证。
- 审批竞争、任务中断、失联重连等状态通过真实事件或可重复场景验证，不以静态截图代替行为验收。
- Windows 与当前环境能够执行的检查在当前环境完成；依赖 Windows 环境的检查转 GitHub Windows runner。
