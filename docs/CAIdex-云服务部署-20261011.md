## 运维入口

```sh
sudo systemctl status caidex nginx postgresql@17-main
sudo systemctl list-timers 'caidex-*' certbot.timer
sudo journalctl -u caidex -u caidex-backup -u caidex-prune -u caidex-monitor
sudo journalctl -t caidex-alert
sudo systemctl start caidex-backup.service
```

恢复仅用既有 [备份操作](../cloud/postgres/operations/README.md) 新建caidex_restore_*隔离库，不覆盖在线库、不重用旧认证/许可、不自动发布。供应商秘密后续只在服务器安全输入到Broker；开邮件前须配置真实from、已验域名/Key、认证webhook与预算，不把秘密贴到聊天中。

软件安装及入口配置参照[PostgreSQL官方Ubuntu仓库](https://www.postgresql.org/download/linux/ubuntu/)、[pgvector官方源码](https://github.com/pgvector/pgvector)、[Nginx限流文档](https://nginx.org/en/docs/http/ngx_http_limit_req_module.html)、[Certbot操作文档](https://eff-certbot.readthedocs.io/en/stable/using.html)，实际版本与验收以本次证据为准。
